# 猎人营地 · 显卡降压（VF 曲线）

给 HUNTER CAMP 首页加了一张 **显卡降压** 卡片，点进去可以拖动电压/频率曲线并应用（等价于微星小飞机的降压曲线，但不依赖小飞机）。

## 它做了什么

1. 首页「基础优化项」那一行多出第 7 张卡片：**显卡降压 / 调电压曲线**。
2. 点卡片打开面板：
   - 上方是当前显卡的电压→频率曲线（实时从驱动读取）；
   - 拖动圆点或「电压上限 / 频率」两个滑块，红色预览线表示降压后会被"削平"的曲线；
   - 预设按钮 900 / 925 / 950 / 975 / 1000 mV 一键设定；
   - **应用** = 把上限之上的所有频点压到上限频率（真正的 NVAPI V/F 曲线写入）；
   - **恢复默认** = 清空所有偏移，回到显卡默认曲线。
3. 应用后 GPU 的最高频率会锁在上限频率，电压随之下降 —— 这就是小飞机里"拉平曲线"的等效效果。

## 后端为什么要有

NVAPI 的 `SetClockBoostTable / SetPstates20` 需要 **管理员权限**，而 HUNTERCAMP 以普通用户运行。所以由一个常驻的小服务（计划任务 `HunterCamp-GpuSvc`，SYSTEM 权限，登录时启动）监听 `http://127.0.0.1:8977/`，只对本机开放：

- `GET /ping` → 服务与 GPU 名称、是否管理员
- `GET /curve` → 127 个频点（mv / mhz / base / delta）与当前上限
- `GET /apply?mv=925&mhz=2535` → 拉平曲线
- `GET /clear` → 恢复默认

网页端用普通 XHR 调用（服务返回 `Access-Control-Allow-Origin: *`），日志里能看到每次请求，可用来验证网页是否连上了服务。

## 使用

1. 打开猎人营地（`Win+Shift+G`），首页最右边就是「显卡降压」卡片。
2. 点开，选预设或拖滑块，点 **应用**。
3. 想回默认：点 **恢复默认**。

命令行也可用（需管理员）：

```powershell
& 'C:\ProgramData\HunterCamp-GpuSvc\HcGpuSvc.exe' --once curve                    # 读曲线
& 'C:\ProgramData\HunterCamp-GpuSvc\HcGpuSvc.exe' --once apply --mv 925 --mhz 2535  # 降压
& 'C:\ProgramData\HunterCamp-GpuSvc\HcGpuSvc.exe' --once offset --khz 150000        # 全曲线 +150MHz
& 'C:\ProgramData\HunterCamp-GpuSvc\HcGpuSvc.exe' --once clear                      # 清空偏移
```

## 注意

- **不要和小飞机同时用**：两边都是同一套 NVAPI 私有接口，会互相覆盖（你之前遇到的"AB 开着其他应用崩"也和这个有关）。
- 降压的稳定性取决于芯片体质：925 mV / 2535 MHz 是常见保守值，出现花屏/驱动重置就往上抬 25–50 mV。
- 写入的是**运行时**状态，重启后由驱动恢复默认；猎人营地自己的"默认开启GPU超频"仍会在启动时加它的偏移（你当前是 +150 MHz）。
- 卡片行原本按 6 张排布，加第 7 张后脚本会把整行压窄（1.29rem → 1.16rem），原卡片副标题可能换行，属正常现象。

## 技术备忘（踩过的坑）

- 曲线表：控制表 9248 字节，第 i 个点的增量在 `0x64 + (i-1)*36 + 0x18`（kHz，有符号）；状态表 7208 字节，条目 `0x40 + i*28`，`+0x04` 类型（0=核心/1=显存）、`+0x08` 频率 kHz、`+0x0C` 电压 µV。
- 掩码从 `GetClockBoostMask` 读出的 6188 字节里取 `[4..36)`。
- 曲线图按 `devicePixelRatio` 设置画布后备分辨率（CSS 尺寸 × 系统缩放），高 DPI 屏幕下网格线、文字和曲线都是清晰的；窗口缩放时会自动重算。
- 画布高度 272px，绘图坐标全部用 CSS 像素，`ctx.setTransform(dpr,0,0,dpr,0,0)` 统一缩放；当前曲线用青色虚线叠在降压曲线之上，便于看清被削平的那一段。
- 私有函数 ID：`SetClockBoostTable = 0x0733E009`、`GetClockBoostTable = 0x23F1B133`、`SetPstates20 = 0x0F4DAE6B`、`GetPstates20 = 0x6FF81213`。
- 结构体版本号用 `size | (ver << 16)` 传入；本卡是 v1 / 9248 字节。
- 非管理员写入返回 `rc = -137`。
